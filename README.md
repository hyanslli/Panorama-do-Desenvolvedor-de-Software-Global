
# 📊 Global Tech Talent Analytics - Panorama-do-Desenvolvedor-de-Software-Global

Projeto *End-to-End* de Business Intelligence que transforma dados da pesquisa global do StackOverflow em insights estratégicos de contratação e retenção de talentos.

## 🏗️ Arquitetura Técnica

- **ETL (Pentaho Data Integration):** Tratamento de dados, *lookup* dimensional e limpeza de *Case Sensitivity*.
- **Database (PostgreSQL):** Modelagem **Star Schema** para alta performance.
- **Power BI:** Dashboards dinâmicos com *Field Parameters*, cálculo de ponto médio salarial e filtros de segurança estatística (*Top N*).

## 💡 Insights Gerados

- Mapeamento global de **Custo x Senioridade** para estratégias de *Offshoring*.
- Correlação entre **Modelo de Trabalho (Remoto/Híbrido)** e índice de satisfação.
- Análise demográfica e salarial detalhada por Stack Tecnológica.
